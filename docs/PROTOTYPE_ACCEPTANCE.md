## PMO操作

1. 设置恢复样例；日轴拖到09:10/09:25/09:45和10:00，依次核对群聊、会议、私聊与未记录；修订对象/摘要。
2. 缩小进入月历，14/15日时序与日轴相同；其他日期未记录，打开15日日报及所在周周报，生成含明确Timeline的正文。
3. 主动发现查看文档两次证据，试稍后/忽略/恢复，再接受保存Skill。
4. Agent连接模拟检测Codex；执行正常生成，在差异处停下，再确认应用。重新生成应无变化。试模型失败、冲突和取消，不能假成功。
5. 接受配券候选保存，执行只显示预览；Claude不可点。刷新状态保留，删除来源阻断复用，重置可重演。
