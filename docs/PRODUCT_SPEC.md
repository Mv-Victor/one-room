# 产品规格 v0.2

优先级以PROJECT/MVP为准：P0核心为时间轴、周期总结、日月回顾及日报周报；P1次核心先交付文档SOP发现、Skills与Codex复用；P2随后交付配券/策略SOP。旧白板/浏览器/团队页面为后续探索。HTML使用虚构数据，采集、AI、探查和Codex均模拟。

## 1. 时间轴

首屏参考用户提供的Screenpipe布局，仅替换为One Room的绿色品牌色：左侧紧凑导航，上方日期/回放/倍速/缩放/搜索，中央全宽截图回看，下方时间轨道与带文字游标。周期摘要为紧凑信息区，详细周期列表在下方；不做首屏双栏证据卡片。软件/日期/文本筛选共同生效。白板/旧浏览器/团队入口收进“后续探索”。

原型的播放、上一/下一事件、1×/2×只回看预置样例截图，不是实际录屏视频；必须持续标注模拟。正式版回放按采集时间映射图像，不声称静态截图间存在真实视频帧。

- 铆钉形游标就地清楚显示时间、软件、当前活动、对象与主题，不必打开详情；点击事件跳到起点，左右拖游标选时点，空轨道横拖平移。缩放围绕游标，所有操作不修改采集事实。
- gap显示“未记录”，不能沿用前一工作标题或截图。事件无截图显示证据缺失；短事件有最小命中范围但不夸大真实时长。
- 显著切换包括应用、窗口、聊天对象/群、会议、文档和持续主题变化；同软件切群也切周期。
- 周期含起止、时长、软件、类型（私聊/群聊/会议/文档/后台）、对象、主题、摘要、结果和证据。时间/软件为事实，内容推断和人工修订分别标识；未知对象不猜，主题待确认。
- 显著切换后前一周期进入总结：Kim私聊显示聊天对象及主题，Kim群聊显示群名及主题，会议显示可见会议主题，编辑文档显示目标及编辑主题；未授权或内容不足显示待处理/未知，不从会议画面推测未采集的口头结论。
- 短切换沿用固定版本Screenpipe的连续应用分组思路，已采到的A→B→A保留三段，不设“少于30秒就折叠合并”的规则。窄片段可精简常驻标注，悬停/选中/放大可查，当前游标仍显示完整活动标签；月格按时序保留短片段，B时长不计入A。周期总结为One Room增强，内容不足显示事实和未知，不把应用分组等同于逐切换AI总结。暂停/锁屏/睡眠/禁用形成gap，时长不重叠。编辑、拆分、合并保留修订及证据；人工合并仅同日连续且无gap，不能跨筛选隐藏的片段。
- 连续周期与逻辑工作实例分开：工作A→工作B→工作A可续接原A实例，日轴仍显示三段；A只累计自己的两段时间，不计B或gap。对象与业务目标不确定时可确认、续接或拆分实例，修订不覆盖原始时间事实。

## 2. 语义缩放与月历

层次：局部1小时 → 4小时 → 全天 → 月历。日轴持续缩小至全天后继续缩小时自动进入月历；反向放大或选日返回保留日期和游标/窗口，跨层滞回避免抖动。支持上/下月。

macOS三指放大/缩小为专项目标，须在两台Mac记录系统设置、真实手势与输入信号；标准pinch可能以wheel+ctrlKey或Safari gesture到达，不能据此声称识别三指。三指可能被系统辅助缩放/拖移截获，原生适配可行性须验证。只在时间轴区消费缩放信号，不全局抢系统手势；提供日/月分段按钮、缩放图标和键盘等价入口保证受阻时仍可导航，备用操作通过不等于三指通过。

月格按时序列出当天全部周期的时间/软件/对象主题，含记录分钟与覆盖状态；密集格内部滚动。不把无记录写成休息，不把部分采集当全天覆盖。点日格可返回日轴、该日日报及所在周周报；无草稿进入生成态。周一为周首，按工作空间时区计算。窄屏可呈现同月逐日列表。

## 3. 主动发现

主动发现由可自注册的检测worker提供提示逻辑，共用调度和提示状态；重复候选是提示类型之一，未来单次事件提醒也可扩展。首版优先覆盖日报/周报/普通文档三类更新，用户无需编写检测器；配券/策略等选定SOP随后，新增逻辑无需改采集/时间轴/主分发流程。规则设置可查看启用状态、处理进度与故障；单个规则失败不阻断采集及其他检测，重放和重启不重复提示。

发现采用跨应用的通用活动事件：关联a11y正文、OCR、窗口/对象线索、可用控件状态与输入时序，记录查看、疑似编辑、切换或未知，以及观察/推断/确认状态。无需先注册本地文件。文档候选至少两个不同的疑似更新工作实例，同一实例多段活动或多截图只算一次；切窗和静置不直接结束实例。业务对象相同但目标/日期更新不同可形成新实例，关联不足保留待确认。选定SOP按明确步骤、对象/业务轮次与结果识别；既有配券/策略示例按三个不同有序实例提示，仍只沉淀/预览。正文变化不能单独证明编辑、保存或提交，滚动、刷新和协作变化保留歧义。

提示展示规则来源、原因、事件/实例证据、最近时间、目标线索、置信与待确认项，并提供规则声明的动作。重复/SOP沉淀类候选接受后进入Skill草稿，不自动执行；其他提示可只查看或处理提醒，无需生成Skill。确认实例与目标身份后才能形成可执行规则，同名不足以确认同一目标。重复提示相同对象线索+模式24小时不重复，稍后24小时，忽略同模式抑制，支持恢复；状态跨检测重试/升级保留。已有Skill显示更新版本与差异。来源不足、同名多目标和权限失败保留待确认候选与输入，可补充身份或修正行为；首版执行时再选择本地Markdown目标。

## 4. Skill

文档Skill字段：名称、用途（日报/周报/普通文档）、目标引用/connector、格式保留规则、章节/日期更新位置、来源范围、变量、去重、成功条件、证据和版本。日报按日期块更新，已有日期显示替换差异，不重复追加；普通文档明确标记范围，不套日报格式。

candidate → draft → ready(vN)；编辑ready建立草稿，保存新版本，历史Run不变。用户确认目标和规则后才能执行，Skill版本不等于文档版本锁。导出真实Markdown/JSON。

配券/策略Skill可沉淀变量、前提、审批和验证，只预览，不真实发券/投放。旧报表DOM流程不替代Codex文档主线。

## 5. Codex执行与连接

Codex状态：未安装/未认证/可用/执行中/故障；检测不发付费推理请求，登录由用户在本机完成。Claude置灰“暂未接入”。摘要模型单列，与Codex认证独立。后台摘要/事件分析的文字发送默认关闭，用户单独开启后持续处理获准应用的提取文字，设置跨重启保留；关闭或移除获准应用后停止对应新请求、取消未发送任务并丢弃迟到结果。截图不自动发送；未授权分析仍可本地采集、提取和回看，Codex仍逐次确认输入及差异。

固定Skill版本 → 选日期/来源 → 读目标快照 → 确认输入范围 → Codex生成建议 → 结构化校验 → before/after差异 → 本人应用 → 重读验证。当前文件hash变化进入conflict，重读重算不覆盖；非目标段落字节一致，目标日期唯一、格式符合才成功。

状态：queued → reading → generating → awaiting_review → applying → verifying → succeeded；非终态可failed/canceled；应用冲突为conflict，新生成用新Run。取消生成丢弃迟到结果；应用开始后取消需核验，不谎称回滚。重启中断标interrupted，不自动续写。

异常有未安装/未认证、读写权限、不支持格式、模型超时/无效结果、来源删除、并发修改、应用失败、取消。均有重试/重选目标入口；相同已提交operation不得重复写。原型清楚显示模拟，无真实凭证输入。

## 6. 报告与数据

日报周报含明确时间/软件/对象主题/业务内容/结果/证据Timeline、覆盖日期和未记录说明。周报只汇总已有日期。人工修改不改变采集事实，来源改变提示过期。发布固定快照、撤回隔离沿用旧约定；管理者功能后置，不做活跃排名。

原型localStorage恢复视图、游标、Skill、候选和报告；导出产生真实文件。删除轨迹清证据、候选、报告；保留文字Skill时标来源删除并阻断旧来源执行。重置恢复样例。模型设置不接收真实Key。

## 7. 验收

P0：左右拖动游标就地读当前工作→四类对象/主题周期总结→缩小自动月历→月格时序→日报/周报入口；验证空白/空月、定位/覆盖及两Mac三指真实信号。

P1：日报/周报/普通文档候选→Skill→读取当前文档→Codex沿用格式生成差异→人工确认→写回验证；还需冲突、取消和失败恢复。P2：配券/策略候选→规则编辑→导出/预览。Claude始终不可启用。桌面1440×1000和手机390×844可导航、不溢出不遮挡。真机手势、云文档写回、配券审批见BOUNDARIES，不以HTML测试替代。
