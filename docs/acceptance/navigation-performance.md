## 复现与环境

```sh
npm run build
npm run benchmark:navigation
```

入口为 `scripts/benchmark-navigation.mjs`，构建 `tests/integration/navigation-benchmark.ts` 至 `out/main/navigationBenchmark.js`，由 Electron 的 Node 模式执行；该入口已从产品安装包排除。本次也通过 `npm run typecheck`、`npm run lint` 与 `npm run build`。没有为满足阈值修改生产查询或降低门槛。

机器：Apple M4 Pro，14 个逻辑 CPU，24 GiB 内存，macOS Darwin 24.6.0，arm64。运行时为 Electron 42.11.14、其内置 Node 24.19.0、SQLite 3.53.2、数据库 schema 3；构建宿主 Node 为 22.22.2。

每次在临时目录创建全新库，结束后删除，不读取用户屏幕历史。合成范围为上海时间 2026-11-01 00:00 至 2026-12-01 00:00，共 30 天；100,000 条观察，每 10 条相邻同义观察合为一个周期，共 10,000 个语义周期。前 29 天各 334 个周期，末日 314 个；两种应用交替。另有 100,000 个图片引用、1,000 个内容不同且写入文件的 1×1 PNG blob、1,000 条选中文本。数据库文件 179,523,584 字节（171.21 MiB）；准备样本耗时 5,183ms。

首次全范围读取使用新建 worker，包含 worker 启动和连接初始化；建库已使系统文件缓存变热，未清 OS 缓存，不能将其称为冷盘结果。后续请求串行执行，开始前已完整读取一次，SQLite/OS 缓存可为热状态；没有并发采集或图片解码。

## 服务基准的范围

- 测量停在 worker/领域服务，没有经过 renderer/main/preload IPC、DOM 绘制、实际截图读取和浏览器图片解码；100 次定位返回证据描述，未加载图片像素。1×1 合成 PNG 不能代表真实桌面截图负载。
- 20 次操作是 10 次日查询与 10 次月查询，未驱动真实日/月界面或物理三指手势。完整界面已在下述复测补齐，两台 Mac 与物理手势仍待。
- 未强制清系统缓存，未测并发采集/模型分析、CPU 使用率、峰值内存或耗电，也不将单机暖缓存结果推广到所有设备或任意历史规模。
