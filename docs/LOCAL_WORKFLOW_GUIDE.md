# One Room 本机流程使用指南

## 已交付的链路

重复行为候选 → 确认 SOP → 关联一次明确授权的浏览器录制 → 填写本次参数 → 自动执行 → 核验结果。

候选发现不会擅自执行。时间线事实和语义任务可以提供重复行为的证据，但不能直接还原每个可点击元素；首次执行需要录制示范。

## 发现重复行为

1. 在原有采集和分析设置中配置需要观察的应用。模型语义分析仍依赖对应分支的模型配置和授权，不是本地流程引擎自动提供的能力。
2. 至少两个独立实例具有相似有序步骤后，SOP 工作台会显示候选。ML 分支同时读取 MemoryLane 的语义任务聚类。
3. 查看步骤、重复实例和来源任务，选择接受、稍后或忽略。单纯浏览、同一对象的短时切回以及重叠证据不能重复计数。

当前内置文档、策略和通用行为三类探查规则。其他主动提醒可通过注册规则扩展；这里的规则是随应用交付的可信代码，不是任意第三方插件。

## 录制一个可执行流程

1. 打开「SOP 工作台」，选择「新建录制」，填写流程名称、起始页面地址和可变字段名称。
2. 可变字段使用目标表单的 `name` 或 `id`，例如 `title,owner`。本轮实现尚未提供可视化选字段工具。
3. 确认录制授权，应用会打开独立浏览器。先完成登录，再回到 One Room 点击「开始记录操作」。不要录制密码或登录步骤。
4. 在该浏览器中示范业务操作。保持窗口大小，步骤间稍作停顿，完成后点击「结束录制」。
5. 等待状态变为「可复用」。如页面布局不支持或素材不足，应用会停止并保存日志，不伪造可执行流程。

## 发布和复用

1. 接受通用行为候选，或点击「新建 SOP」，执行方式选择「本地流程 · 浏览器操作」。
2. 关联已完成的录制，确认用途、操作范围、变量、来源和结果标准。
3. 如目标提供同源、无需额外认证头的只读 JSON 接口，可填写结果核验地址及字段路径，例如 `/title` 对应参数 `title`。此接口必须真正只读。
4. 点击「确认并发布」。每个版本绑定全部录制素材的摘要，不能修改旧版本来替换实际操作。
5. 点击「复用」，填写这一次的参数并确认执行。中文参数可直接使用。

## 如何理解执行结果

- 成功：录制步骤完整执行，独立回读匹配，并且能观察到实际状态变化。
- 无需修改：执行前目标已满足核验条件，没有再次提交操作。
- 结果待核验：没有核验接口、回读失败、被中断或结果不符。不会自动重试写入。
- 已人工核验：用户已到实际系统检查结果并明确确认，不等同于自动验证成功。

「核验实际结果」只读取，不重放操作。「人工核验」也不重放，只记录确认并结束待核验状态。重启不会自动续录或自动重放。

## 当前边界

- 实际执行使用 OpenAdapt Flow 2.0.0，Python 和 Chromium 已打包到桌面应用，无需用户另装。
- 当前支持单个浏览器页面及同源导航，不支持任意原生 Mac 应用、多窗口操作、验证码或任意弹窗。
- 本地引擎不需要 Codex 登录。Codex 公司文档链路按用户要求未做真实登录和写入验收；001 分支仍保留同事设计的执行门禁。Claude 保持置灰。
- 配券和策略候选仍只保存规则和预览，不启用生产操作。
- 已验收的是本机开发包，尚未进行 Developer ID 签名、公证、第二台 Mac 安装和完整采集硬件验收。
- 这次新增流程、导航及常用活动/模式状态已中文化；MemoryLane 原有高级配置中仍有英文，未宣称全量汉化完成。

## 重复验收

在准备运行时并打包后运行：

```sh
node scripts/verify-sop-desktop.mjs
node scripts/verify-workflow-desktop.mjs
```

如当前仓库未安装 Playwright，可用 `ONE_ROOM_PLAYWRIGHT_MODULE` 指向已安装的模块。脚本使用隔离用户目录和本机表单，不读取普通用户历史，不修改公司系统。

验收回执和截图位于忽略的 `.desktop-acceptance/` 目录。详细技术说明见 [SOP_DISCOVERY.md](SOP_DISCOVERY.md)。
