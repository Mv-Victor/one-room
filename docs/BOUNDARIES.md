# 边界与待讨论决策

以下默认值支持直接开工；接入未验证不称已具备。

| 问题 | 当前默认 | 责任与验证 |
| --- | --- | --- |
| 必须精确三指？ | 三指放大/缩小为目标，两Mac实测配置与信号；系统拦截时保留备用日/月操作，不将备用通过计为三指通过 | B负责导航与真机记录，A接main信号；不强抢系统手势，记录通过/受阻 |
| 首个文档目标？ | 用户选择本地Markdown；云Docs下一connector | 两人准备测试文档；A负责读取/事务/执行审核，B负责Skill规则 |
| Kim对象/主题？ | 窗口/OCR可见内容，推断标注、可修正 | A/B测未知与误识别；不读聊天数据库 |
| 一次更新定义？ | a11y/OCR通用事件关联逻辑工作实例；A→B→A续接同一A，按不同实例计次，确认后才计已确认更新 | B处理对象/业务目标和关联修订；PMO标真值；不按切窗/静置新建，不补gap |
| 主动提示如何扩展？ | 内置检测worker自注册，共用调度/授权/状态/去重；P1覆盖日报/周报/普通文档更新，P2配券/策略等选定SOP随后 | B验证故障隔离及重放；每条规则定义触发与动作，未来单次提示无需重复次数或Skill |
| Agent认证？ | 本机Codex CLI；摘要模型独立配置；Claude禁用 | A在T047验证CLI版本/认证并展示连接状态；GPT兼容URL不等于Codex登录 |
| 模型Key用于什么？ | 本地AX/UI树与Vision OCR无需Key；后台文字模型独立配置 | A在T064做配置/安全凭证/合成测试，T021做队列；读取只返hasCredential，连接测试不启用文字授权 |
| 无人写日报？ | 每次差异确认后应用，首版不自动后台写 | 后续另设目标白名单/定时授权/撤销 |
| 配券复用边界？ | 发现、Skill、参数、预览，不发券/投放 | 系统Owner接口/审批另行接入 |
| 管理者原轨迹？ | 不共享，后续仅本人发布报告 | PMO沟通个人价值，不做活跃排名 |
| 白板取消？ | 移出MVP关键路径，保留探索 | P0全过再评估 |
| 仓库与线上？ | 主仓库15；线上静态原型使用独立Sites发布副本 | 延续已授权的线上体验同步，保留仅本人受众；不push公司Git远端 |

最关键的后续决策：首个真实目标是否必须公司云文档。若必须，先验证读取、版本/条件更新和授权；无条件更新能力时不能承诺覆盖式自动写回。当前本地Markdown闭环仍完整交付。
