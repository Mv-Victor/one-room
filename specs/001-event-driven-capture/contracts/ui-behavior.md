# 时间线与执行界面行为

状态：设计待实现，依据 [spec.md](/Users/huangzhidong/work/one-room/tianmu-hackthon-15/specs/001-event-driven-capture/spec.md)。Screenpipe 固定版本为时间导航参考，One Room 增加对象/主题周期、日月切换与报告；不把上游分组当成自动摘要实现。

## 1. 首屏及选择状态

默认进入最新录制位置的时间线，短录制自动适配可见跨度，不固定显示零点至午夜。主要区域为画面、就地活动标签和底部真实时间轨道；紧凑工具栏提供日期/回到最新录制、播放、应用筛选、搜索、缩放及独立助手范围选择。导航可进入报告、发现、Skill、执行记录与设置，再返回原时间位置。使用已选图标库的图标按钮和 tooltip，缩放有可访问的按钮/输入，Claude 可见置灰。空数据直接呈现空轨道和采集状态，不填示例轨迹。

共享导航状态为 `{mode:"day"|"month", selectedDate, cursorTs, daySpanMs, filters, assistantRange, queryRevision, selectionGeneration}`。cursorTs 与助手范围独立；拖游标不扩大已确认的模型输入。日期键使用 Asia/Shanghai；软件筛选不改时间坐标，不改变完整日/周报告范围。返回时间线恢复此前选择，已删除或失效时重新定位并显示原因。

每次改变游标/过滤/日期提升 selectionGeneration。异步结果必须匹配 generation、queryRevision 和 requestToken；乱序返回不得覆盖当前选择。连续回看时仅在同一有效周期、来源版本与证据有效期内保留已载入的前一画面，并显示真实 observedAt；跨周期、缺口、删除、过期或证据晚于游标立即清图。跨午夜本身不清除仍有效的画面。文本、周期与图片状态分别呈现，文字失败不隐藏有效截图，截图到期也不隐藏有效文字。

## 2. 游标、周期和真实覆盖

- 铆钉形游标可左右拖动，标签紧邻游标或在画面边缘固定的同一标签区；无需详情即可读到时间、软件、动作、对象、主题。未知/待总结明确显示，长文本换行或限制行数后可展开，不能盖住相邻控件。
- 播放按真实时间推进，gap 保留空白/未记录，不能用上一张图填补。画面同时显示其实际 observedAt；游标在观察支持范围内显示该证据，不把它描述成逐帧录像。
- 时间轨道、月格及统计全部读取同一事实投影。周期使用半开区间，未知覆盖不向现在无限延伸，gap 不计工作时间。小于可读宽度的片段可以减文字，但保持可发现的命中区域、选中列表项和放大定位。
- 轨道从首条未删除观察至最新已知录制边界连续浏览；截图到期不缩短文字历史，主动删除重新计算边界。固定中心游标配合横向触控板滚动/拖动，平移和播放可跨午夜，日期随游标同步；日期仅用于定位、统计和日历，不截断轨道。边界外仅留空白，不画全天刻度或伪造未来记录。前后各预载一个本地日，跨日加载不反复清空旧的有效范围。
- A→10 秒 Kim→A 保留三段和真实时长；无最小 30 秒合并/删除。视觉压缩不改变区间、排序、实例计次或报告。高密度点选可显示按时间排序的候选列表，避免扩大命中区域后遮住相邻片段。
- `available` 加载有效图；`expired` 显示“原图已过期”；`deleted/missing/none` 使用各自明确状态；gap 显示“未记录”。任何非 available 状态均清除旧图，不拿同 blob 的其他有效 ID 绕过旧证据过期。

显著应用/窗口、聊天对象/群、会议、文档或持续主题切换建立前一周期边界并安排总结；不要求每次输入/每个切换单独调用模型。总结字段包括起止、真实时长、软件、动作、对象、主题、摘要和来源。Kim 私聊的对象与正文中提到的人分开，群名与讨论主题分开；会议只展示可见主题及屏幕信息，无音频结论；文档不能仅凭变化称已保存。摘要有 `not_authorized|pending|ready|failed|insufficient` 状态，事实仍可读。

人工更正记录 revision 和依据，原观察保留；后台任务不得覆盖人工锁定内容。用户可从周期/事件查看来源并纠正身份/行为，从实例查看关联并续接/拆分；修订后重新查询和重算候选。

## 3. 日/月缩放状态机

首版连续时间轴可见跨度为 10 秒至 24 小时，初始按实际录制范围适配并限制为至多 1 小时；围绕固定中心游标缩放，导航边界是实际录制起止而非午夜。一个本地日仍用于 Asia/Shanghai 统计投影；源时间始终 UTC。标准 pinch 与带缩放修饰键的 wheel 使用标准增量，普通纵向滚动仍用于列表/滚动区域，图标按钮/输入走同一导航 reducer。连续信号可平滑变化，离散 swipe 以动画步进呈现，不能声称获得手指距离。

| 当前状态 / 输入 | 结果 |
| --- | --- |
| day，尚未覆盖全天，zoom out | 扩大跨度至全天，保持 cursorTs 锚点 |
| day，已全天，继续 zoom out | 跨入 selectedDate 所在月；连续信号累计一个额外缩放步再进入，避免单个微小尾事件误切 |
| month，zoom in | 返回选中日期的日轴，恢复该日最近 cursorTs，未浏览该日则定位首条有效周期或中午空位 |
| month，选择某日 | 选中日期；明确打开/双击进入日轴，日报/周报按钮直接进入对应报告 |
| day，zoom in | 缩小跨度，最小值处保持稳定；不能越界压缩真实区间 |

“一个额外步”为 reducer 的归一化单位，不依赖设备原始 delta 常量；实现时记录归一化映射。跨层立即清空累计增量、同一手势结束前禁止再次跨层，反向新手势才能返回；swipe 每次视为独立手势并去除重复序号。日/月转换保留 selectedDate/cursorTs，跨月选择更新 month，重置旧查询。禁止正反边界抖动或使用每个 wheel 事件直接切换视图。

macOS 三指首先验证 Electron BrowserWindow `swipe` 信号：时间线获得焦点且手势命中其区域时，up 放大、down 缩小，left/right 不重载为缩放；不能取得可靠命中范围时忽略该信号。该系统事件依赖“在页面之间轻扫”等系统设置，只提供方向；按两台目标 Mac 的真实信号和体验决定支持矩阵。标准 pinch/wheel 没有手指数，不能据此宣称三指通过。系统拦截时显示兼容状态，按钮/标准缩放完成同一日月流程；SC-015 单独记受阻。

## 4. 月格与报告

月视图按周一开始排布，有固定网格尺寸和日格内部滚动/展开，工作行按真实 startTs 排序并含时间范围、软件、动作、对象/主题。显示覆盖状态，未采集日期为空，部分覆盖不称全天。窄窗口改为逐日列表，每日仍可浏览所有工作、日报及所在周周报。全月只查摘要与覆盖，截图在用户定位后再加载。

日报/周报打开完整当地日/周（周一至下周一），显示来源、记录时长、缺口/覆盖和内容 revision。入口状态 `absent|draft|ready|failed|invalidated`；不存在时可生成事实日志，模型信息未授权时保留事实；若用户要求写外部文件而目标未配置，进入目标配置状态。本地报告与用户日报/周报文档是两个实体，只有明确 linkedTargetId 才关联。重新生成需更新 revision，不悄悄改旧报告快照。

## 5. 主动发现与执行

发现列表按重要性及时间展示，文档三类优先、配券/策略随后。每项包含检测规则、实例/来源、推断依据、待确认项及接受、忽略、稍后动作；查看规则故障不影响采集。A→B→A 是三个连续片段、两个逻辑实例；A 只计一次，时长不含 B。相同标题、滚动、自动刷新和协作变化保留疑问；接受文档候选先确认两个不同实例及目标/范围，未解决则留草稿。

Skill 编辑/版本界面区分草稿与就绪，修改创建新版本。配券/策略确认变量/步骤/结果/审批后只能导出/预览，执行按钮不能发真实业务请求。新增内置 worker 的提示种类可复用通用列表/动作，不把所有提示都解释成重复 SOP。

文档复用默认 Codex。执行先展示当前目标及选定来源、规则版本、章节和将发送的完整文字，用户确认后进入 generating；完成仅进入 awaiting_review。展示应用生成的完整差异、保留范围与校验问题，再次明确确认才 apply。生成/审核可取消；applying/verifying 显示实际阶段并禁取消，继续核验/恢复。状态及错误遵循 [desktop-ipc.md](/Users/huangzhidong/work/one-room/tianmu-hackthon-15/specs/001-event-driven-capture/contracts/desktop-ipc.md)，核验完成前不显示成功。

过期、来源删除、认证/能力失败、超时、无效建议或目标变化均展示可操作状态，重新准备须重新确认输入和差异，不能静默重试写入。独占编辑不能确认时提供补丁导出。后台文字分析开关与本次 Codex 输入授权分开；Claude 置灰且注明“暂未接入”。
